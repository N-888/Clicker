# Clicker   /   Веб-сайт с подсчетом кликов
1. **Красивый современный сайт** с градиентами и анимациями
2. **Адаптивный дизайн** для всех устройств (телефоны, планшеты, ПК)
3. **Полноценная система пользователей** с регистрацией и авторизацией
4. **Игра-кликер** с сохранением прогресса в базе данных
5. **Интерактивные элементы** с анимациями при наведении
6. **Валидация форм** с подсказками и индикаторами
7. **Всплывающие сообщения** об успешных действиях
1. **Главная страница** (`/`) - показывает статистику игрока
2. **Регистрация** (`/register`) - создание нового аккаунта
3. **Вход** (`/login`) - авторизация пользователя
4. **Выход** (`/logout`) - завершение сессии
5. **Кликер** (`/click`) - основная игровая механика
6. **База данных** - хранение пользователей и их прогресса
7. **Безопасность** - пароли хешируются, сессии защищены
